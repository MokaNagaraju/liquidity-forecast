How the System Works

  1. Generate entities, bank accounts, ledger, receivables, payables and FX rates
  2. Calculate current ledger balance + expected inflows − expected outflows
  3. Run three scenarios: Base, Delayed Receipt, Stress
  4. Flag known data problems using ground truth
  5. Show everything in this dashboard
